如何添加或启用

编辑 pii_engine/engines/presidio.py，在引擎初始化时注册需要的识别器。类型筛选使用 Presidio 原始大写标签，接口返回使用上表的项目输出名称。

# 已注册类型：按请求筛选；不会自动注册尚未启用的类型
results = analyzer.analyze(
    text=text,
    language="en",
    entities=["US_BANK_NUMBER", "EMAIL_ADDRESS"],
)

# 查看当前语言实际注册的类型
print(sorted(analyzer.get_supported_entities(language="zh")))

US_BANK_NUMBER 已默认注册到英文引擎，不需要再加映射才能检测；但中文引擎没有自动注册这一美国专用识别器。PRESIDIO_TYPE_MAP 只转换输出名称，不负责启用类型。

模型配置在 presidio-config.json；实际加载语言见 GET /health 的 presidio_languages。本项目现有 config.json 仅支持整个 Presidio 的开关，未提供逐类型的配置项。修改后重启服务。
